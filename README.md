# NBA career trajectories from longitudinal PER: code, data and results

Code, data and results for an analysis of the reproducibility of career-trajectory clustering of NBA players.
The manuscript text and the full citation will be added here after publication.

## Layout
```
code/      analysis scripts; code/run_all.sh runs everything in order
data/      not included in the repository: place the raw download here (see data/README.md and the Data section)
results/   intermediate and final result files (CSV/JSON/NPZ) from which the paper is built
paper/     output folder: tables/*.tex, numbers.tex and figures/ are generated by code/make_numbers.py and make_figures.py
```

Figure files and the figures of the paper: `fig2_pipeline` = Figure 1, `fig1_examples` = Figure 2,
`fig3_reconstruction` = Figure 3, `fig4_single_run` = Figure 4, `fig5_consensus` = Figure 5,
`fig9_continuous` = Figure 6, `fig6_profiles` = Figure 7, `figA1_training` = Supplementary Figure S1.
`fig7_external`, `fig8_sensitivity` and the tables `nesting.tex` and `profilescoarse.tex` are additional diagnostics
that are not shown in the paper.

## Reproduce
```
pip install -r code/requirements.txt
bash code/run_all.sh                    # everything, about 10-12 hours on two CPU cores
```
To regenerate only the numbers, tables and figures of the paper from the result files in `results/` (a few minutes):
```
python3 code/make_numbers.py            # paper/numbers.tex and paper/tables/*.tex
python3 code/make_figures.py            # paper/figures/*
python3 code/fig_pipeline.py            # paper/figures/fig2_pipeline.*
```
This last step was rerun on 10 November 2026 with Python 3.13 and numpy 2.5.3, pandas 3.0.5, scipy 1.18.1,
scikit-learn 1.9.1, statsmodels 0.15.0, matplotlib 3.11.2, diptest 0.12.0 and Unidecode 1.4.0; it reproduced
`paper/numbers.tex` and all tables exactly and all figures with identical content. The full pipeline was run with
Python 3.11, PyTorch, umap-learn 0.5.12, hdbscan and tslearn (lower bounds in `code/requirements.txt`); the autoencoder
and UMAP results can differ slightly between library versions and hardware even with fixed seeds, which is why every
intermediate result is included.
`code/run_all.sh` lists every step in the order in which it was run, with all ensemble sizes. All random seeds are
fixed in the code. On two CPU cores one d = 64 autoencoder takes about 8-15 minutes and the whole pipeline
roughly 10-12 hours.

Main steps:
- `build_dataset.py`, `build_bpm.py`, `build_consecutive.py`: sample construction for all specifications
- `autoencoder.py`: masked Transformer autoencoder (RQ1)
- `clustering.py`, `stability_single_run.py`: 720-configuration UMAP+HDBSCAN grid and its seed stability (RQ2)
- `consensus_kmeans.py`: resampling-based consensus clustering for every representation and reference (RQ3, RQ4)
- `structure_tests.py`, `continuous.py`: gap statistic, dip test and the continuous description
- `mixture_tests.py`, `mixture_diagnostics.py`: Gaussian mixtures calibrated against copula references
- `power_simulation.py`: power of the tests for discrete structure on simulated latent-class populations
- `dip_direction_check.py`: power of the dip test along the most favourable direction in the same simulation
- `latent_geometry.py`: comparison of the latent spaces of different autoencoder seeds
- `evaluate.py`, `make_numbers.py`, `make_figures.py`, `fig_pipeline.py`: evaluation, numbers, tables and figures

## Data
The raw source tables are not included, because the terms of use of Basketball-Reference (Sports Reference LLC) and
NBA.com do not allow republishing complete data tables; `data/README.md` explains how to rebuild them with
`code/00_scrape_bbref.js` and `code/00_fetch_nba_api.py`. All derived data (analysis samples, PER trajectories,
draft links) and all intermediate results are included, so the numbers, tables and figures can be regenerated without
the raw tables. Data from Basketball-Reference.com and NBA.com remain subject to those sites' terms of use.
