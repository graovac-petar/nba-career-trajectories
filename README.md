# Discrete types or a continuum? NBA career trajectories from longitudinal PER

Code, data and results for the manuscript (Graovac, Hadži Pavlović, Radojičić, Radovanović, 2026).

## Layout
```
README.md  this file
code/      analysis scripts (numbered in execution order below)
data/      raw download (Basketball-Reference advanced tables, retrieved 4 Sep 2026), nba_api draft history,
           and the 19-cluster assignment of the 2025 submission (for the comparison in Section 5.9)
results/   every intermediate and final result file (CSV/JSON/NPZ) that the paper is built from
paper/     LaTeX source; tables/*.tex and numbers.tex are GENERATED by code/make_numbers.py
```

## Reproduce
```
pip install -r requirements.txt
python code/build_dataset.py                       # sample construction, all specifications  -> results/trajectories_*.npz
python code/build_bpm.py; python code/build_consecutive.py
python code/autoencoder.py --spec primary --latent 64 --seed 0     # repeat for latent in {8,16,32,64,128}, seeds 0..4, and specs
python code/clustering.py --ae primary_d64_s0      # 720-configuration UMAP+HDBSCAN grid, held-out evaluation
python code/stability_single_run.py                # seed-to-seed reproducibility of single runs
python code/consensus_kmeans.py --rep ae64         # consensus protocol; --rep summary|raw|pca|dtw|summary_null0|summary_copula0 ...
python code/structure_tests.py                     # gap statistic, dip test
python code/evaluate.py                            # external validation of every consensus partition
python code/make_numbers.py; python code/make_figures.py; python code/fig_pipeline.py
cd paper && pdflatex main && bibtex main && pdflatex main && pdflatex main
```
The shell scripts `run_*.sh` show the exact order in which everything was executed. All seeds are fixed in the code.
Hardware used: 2 CPU cores; one d=64 autoencoder takes about 8-15 minutes.

## Data
`data/nba_advanced_1980_2026.csv` was produced by `code/00_scrape_bbref.js` (browser console). Basketball-Reference data
are subject to the site's terms of use. Draft records come from the `nba_api` package (`data/nbaapi_draft_history.csv`).
