# NBA career trajectories from longitudinal PER: code, data and results

Code, data and results for an analysis of the reproducibility of career-trajectory clustering of NBA players.
The manuscript text and the full citation will be added here after publication.

## Layout
```
code/      analysis scripts; code/run_all.sh runs everything in order
data/      raw download (Basketball-Reference advanced tables, retrieved 4 Sep 2026), nba_api season records
           (used to identify careers that began before 1979-80) and draft history
results/   intermediate and final result files (CSV/JSON/NPZ) from which the paper is built
paper/     output folder: tables/*.tex, numbers.tex and figures/ are generated by code/make_numbers.py and make_figures.py
```

## Reproduce
```
pip install -r code/requirements.txt
bash code/run_all.sh
```
`code/run_all.sh` lists every step in the order in which it was run, with all ensemble sizes. All random seeds are
fixed in the code. On two CPU cores one d = 64 autoencoder takes about 8-15 minutes and the whole pipeline
roughly 10-12 hours.

Main steps:
- `build_dataset.py`, `build_bpm.py`, `build_consecutive.py`: sample construction for all specifications
- `autoencoder.py`: masked Transformer autoencoder (RQ1)
- `clustering.py`, `stability_single_run.py`: 720-configuration UMAP+HDBSCAN grid and its seed stability (RQ2)
- `consensus_kmeans.py`: resampling-based consensus clustering for every representation and reference (RQ3, RQ4)
- `structure_tests.py`, `continuous.py`: gap statistic, dip test and the continuous description
- `mixture_tests.py`, `mixture_diagnostics.py`: Gaussian mixtures calibrated against copula references
- `power_simulation.py`: power of the tests for discrete structure on simulated latent-class populations
- `dip_direction_check.py`: power of the dip test along the most favourable direction in the same simulation
- `latent_geometry.py`: comparison of the latent spaces of different autoencoder seeds
- `evaluate.py`, `make_numbers.py`, `make_figures.py`, `fig_pipeline.py`: evaluation, numbers, tables and figures

## Data
`data/nba_advanced_1980_2026.csv` was produced by `code/00_scrape_bbref.js` (run in the browser console).
Basketball-Reference data are subject to the site's terms of use. Draft records come from the `nba_api` package
(`data/nbaapi_draft_history.csv`).
